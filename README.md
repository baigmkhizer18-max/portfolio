# Muhammad Khizer Baig - Personal Portfolio

A modern, responsive, and interactive developer portfolio website built with **React + Vite + CSS3**.

## ✨ Features
- **Hero Section**: Futuristic developer introduction with interactive status tags and action CTAs.
- **MicroSlats WebGL Background**: Sleek, GPU-accelerated motion effect powered by OGL & React Bits.
- **Interactive 3D Spiral Showcase**: 3D infinite spiral helix highlighting key technology horizons.
- **About & Education**: Clean cards with verified academic history (Metropolis Education System & Aptech ACCP AI).
- **Technical Skills**: Animated skill progress bars and category breakdown.
- **Projects Showcase**: Featured frontend and web development projects with live demo links.
- **Contact Form**: Interactive message form with direct email & phone details.
- **Fully Responsive**: Optimized for mobile, tablet, and desktop viewports.

## 🚀 Local Development
```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Create production build
npm run build
```

## 🌐 Deploy to Vercel
1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com/) and click **"Add New..."** -> **"Project"**.
3. Import your GitHub repository.
4. Vercel automatically detects the Vite framework (`dist` folder & `npm run build`).
5. Click **Deploy**.
